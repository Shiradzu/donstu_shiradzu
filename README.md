# Учебный репозиторий: Shiradzu

Репозиторий предназначен для хранения лабораторных, практических и расчетно-графических работ.

## Структура репозитория

- `info/` — лаб Информационные технологии и программирование.
- `AI/` —  лаб История развития и современные тренды искусственного интеллекта.


## Правила ведения репозитория

1. **Структура:** Каждая дисциплина размещается в соответствующей корневой папке.
2. **Ветки:** Разработка и добавление новых заданий ведутся в отдельных ветках с последующим слиянием (`merge`) в ветку `main`.
3. **Коммиты:** Сообщения к коммитам должны быть понятными и отражать суть изменений (например: `Лабораторная работа №2: добавлена блок-схема`).
4. **Чистота:** В репозиторий не добавляются временные исполняемые файлы и кэш компиляторов (`.exe`, `__pycache__`, `.o` и т.д.).
